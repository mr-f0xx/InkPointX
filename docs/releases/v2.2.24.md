## InkPoint X v2.2.24

This release repairs installation and first boot on recent XTEINK X3 production units.

- Releases now include `update.bin`, the exact filename required by stock X3/X4 microSD recovery. It is a byte-identical application image and does not overwrite the bootloader, partition table, NVS, or recovery mechanism.
- A newly installed image is confirmed as soon as storage, the selected display controller, and the first visible UI frame are healthy. A working InkPoint X boot can no longer roll back to CrossPoint merely because the reader was reset during the old 30-second confirmation delay.
- When the live display-controller read is inconclusive on a recent X3, a family-matching factory `hw_calib/screenType` value safely selects the UC8279 driver. Calibration values belonging to another device family are rejected.
- Added host regression tests for OTA health confirmation and X3/X4 controller-calibration isolation.

For a stock X3, place `update.bin` in the root of a FAT32 microSD card and power on while holding the top-left side button. From InkPoint X or CrossPoint recovery, select `firmware.bin` instead.
