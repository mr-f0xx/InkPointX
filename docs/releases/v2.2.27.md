## InkPoint X v2.2.27

This release prevents generated metadata caches from slowing down Gallery startup.

- Gallery indexing always skips dot-prefixed directories such as `.metadata`, `.thumbnails`, and `.crosspoint`.
- Dot-prefixed image files are excluded from the Gallery catalogue as hidden content.
- `System Volume Information` remains excluded on cards previously used by Windows.
- The **Show hidden files** preference continues to control the interactive file browser, but no longer affects the Gallery media index.
- Adds regression coverage for hidden metadata/cache entries, ordinary folders, and visible image files.

The X3 blank-MTP UC8279D display initialization introduced in 2.2.26 remains included unchanged.
