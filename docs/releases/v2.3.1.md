## InkPoint X v2.3.1

Stable maintenance release for the 2.3 dark theme.

- Covers on Home, the recent-books shelf, the end-of-book screen and sleep screens
  keep their original black/white colors in dark mode. Reusing a cached cover does
  not invert it again. The explicit inverted sleep-cover filter remains available.
- Every dark frame uses a full clearing waveform, including reading and menu
  navigation. The panel powers down afterward to reduce residual images and idle
  fading. This intentionally adds a visible flash and a longer page turn.
- Light-mode refresh behavior and grayscale remain unchanged.
- Updated the concise README and user guide with these details.

This is a normal stable release, not an RC. It upgrades both v2.3.0 and older
versions through **Settings → System → Check for updates**.

Universal ESP32-C3 firmware for XTEINK X3 and X4. Use `update.bin` for stock SD
recovery or `firmware.bin` for InkPoint X / CrossPoint recovery. Device-labelled
binaries are identical aliases; verify downloads with `SHA256SUMS`.

Validation includes 184 host tests, localization checks, static analysis,
production-size checks and connected X4 acceptance checks. Framebuffer captures
verify image polarity; they cannot measure the panel's remaining physical ghosting.
