## InkPoint X v2.2.28

This release addresses user-reported sleep-screen artefacts, a wrong reading estimate, and the lack of any usable diagnosis when an over-the-air update fails. It also adds an optional shelf of recently opened books to the home screen.

### Display

- **Sleep screens no longer keep traces of the previous frame.** The battery indicator is cleared from the framebuffer before the "Going to sleep" popup instead of being redrawn into it, so the last interactive frame erases that corner. The sleep image itself is then presented with the panel's own temperature-compensated full waveform rather than the stock "warmed" single pass.
- **Sleep screens land on true white.** The warmed pass was driven as if the panel were at 90 °C, which shortens the waveform enough that white stops a shade short; custom, random, cover and blank sleep screens now use the complete waveform.
- **New setting: Screen → Full Refresh (Complete / Fast).** The periodic page-cleanup refresh, and the manual refresh on the power button, follow it. **Complete** is the new default and is the only mode that returns the page background to white with no residue; **Fast** restores the previous quicker, non-flashing pass for anyone who preferred it.
- On X3, a FULL refresh now requests the same controller resync a HALF refresh already did, so the stronger mode can never leave a weaker baseline behind.

### Reading statistics

- **Time Left is an estimate for the book, not for the current sitting.** It now derives the remaining pages from the whole-book page estimate the status bar and home card already show. The previous formula extrapolated from the pages turned while a statistics file existed for that book, so a book resumed mid-way — restored progress, a percent jump, a rebuilt cache, a device switch — reported roughly a chapter's worth of reading as the whole remainder.

### Over-the-air updates

- **A failed update now names the step that failed.** The failure screen shows a short tag next to the message (`check:http`, `dl:sd-write`, `stage:size 6524000!=6525024`, `verify:5`, `flash:NO_PARTITION`, …) so a report says where the update stopped.
- **The SD card is checked for space before the download starts.** A card without room for the staged image is reported immediately as `sd:space 4M<7M` instead of failing several minutes into the transfer with a generic storage error.
- **Interrupted updates no longer block the next one.** The staging cleanup now removes the hidden transaction siblings the downloader writes alongside `/.ota_update.bin`, not only the final name.

### Home screen

- **New setting: Screen → Recent Books.** When enabled, the Now Reading page shows a shelf of up to three previously opened books under the current one. The side buttons move between the current book and the shelf; Confirm opens whichever is selected. Off by default, because the shelf takes vertical space from the cover.
