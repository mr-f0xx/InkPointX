## InkPoint X v2.3.2

Fixes the dark-mode refresh regression introduced in v2.3.1.

- Ordinary dark-mode page turns and navigation use the same fast panel waveform
  as light mode. Removed the forced full refresh and theme-specific power cycle
  on every frame, which caused the slow light/inverted flashing sequence.
- The finished dark frame is inverted in RAM before a single display submission.
- Covers retain their original black/white colors, including cached covers.
- Reader cleanup follows the existing refresh frequency and depth settings in
  both themes. Switching themes and entering sleep can still clean the panel.

Stable universal ESP32-C3 firmware for XTEINK X3 and X4. Update through
**Settings → System → Check for updates**. `firmware.bin`, `update.bin` and all
X3/X4-labelled images contain the same firmware; checksums are in `SHA256SUMS`.

Validation: 184 host tests, localization validation and connected X4 refresh
traces comparing light and dark mode. The test record includes measured timings.

On the connected X4, ordinary refreshes measured **504 ms in light mode and
503 ms in dark mode**, versus approximately 3729 ms for v2.3.1 dark mode.
[Test record](https://github.com/yokki-vans/InkPointX/blob/main/docs/qa/v2.3.2/README.md).
