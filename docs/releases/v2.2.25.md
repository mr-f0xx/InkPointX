## InkPoint X v2.2.25

This release fixes first boot on newly manufactured XTEINK X3 units with the revised UC8279D display controller.

- Detects field panels whose UC8279D ships with blank MTP metadata and reports an all-`FF` version register.
- Validates two identical, non-uniform MTP readbacks so a floating UC8253 bus cannot be mistaken for the new controller.
- Uses the controller vendor's longer identification reset timing on X3 confirmation passes and releases a retained reset pin before probing.
- Keeps the existing family-matched factory-calibration fallback and leaves older UC8253 X3 and X4 behavior unchanged.
- Adds a regression test covering programmed MTP, stable blank MTP, unstable reads, and floating high/low buses.

The frozen `Update complete` image reported on 2.2.24 was the recovery screen retained by e-ink after the application had already been written. The installer itself succeeded; the old image selected the wrong display driver before its first frame.

For stock recovery, copy `update.bin` to the root of a FAT32 microSD card. From the CrossPoint/Witch Hunt recovery file picker, select `firmware.bin`. Both files contain the same application image and do not overwrite the bootloader, partition table, NVS, or SD recovery mechanism.
