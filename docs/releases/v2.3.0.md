## InkPoint X v2.3.0

- Added a persistent system-wide **Dark mode** toggle under **Settings → Screen & Power**.
  Home, library, settings, book pages and sleep screens use light content on a dark background.
- Switching themes cleans the display baseline. Existing installations default to light mode.
- Reading-only inversion remains available in the light theme; enabling both settings
  keeps pages dark instead of inverting them twice.
- Dark mode uses monochrome rendering. Four-level grayscale and text antialiasing
  remain available in the light theme.
- Device screenshots follow the selected theme.
- Rewrote the README around the essential features, installation and build steps.
  Detailed instructions now live in dedicated installation and development guides.

Universal ESP32-C3 firmware for XTEINK X3 and X4. Based on v2.2.28, including its
sleep-screen cleanup, reading estimates, recent-books shelf and OTA diagnostics.

Update through **Settings → System → Check for updates**, or use `update.bin` for
stock SD recovery and `firmware.bin` for InkPoint X / CrossPoint recovery.
The device-labelled binaries are byte-identical aliases. Checksums: `SHA256SUMS`.

Validation: 182 host tests, all 28 locales, static analysis, production build and
USB acceptance checks on a connected X4. [Test record](https://github.com/yokki-vans/InkPointX/blob/main/docs/qa/v2.3/README.md).
